# 在 Remotion 中使用 Three.js 和 React Three Fiber

遵循 React Three Fiber 和 Three.js 的最佳實踐。
只需遵循以下 Remotion 特定規則：

## 前置條件

首先，需要安裝 `@remotion/three` 套件。
如果尚未安裝，請使用以下命令：

```bash
npx remotion add @remotion/three # 如果專案使用 npm
bunx remotion add @remotion/three # 如果專案使用 bun
yarn remotion add @remotion/three # 如果專案使用 yarn
pnpm exec remotion add @remotion/three # 如果專案使用 pnpm
```

## 使用 ThreeCanvas

你必須將 3D 內容包裹在 `<ThreeCanvas>` 中，並包含適當的燈光。
`<ThreeCanvas>` 必須有 `width` 和 `height` 屬性。

```tsx
import { ThreeCanvas } from "@remotion/three";
import { useVideoConfig } from "remotion";

const { width, height } = useVideoConfig();

<ThreeCanvas width={width} height={height}>
  <ambientLight intensity={0.4} />
  <directionalLight position={[5, 5, 5]} intensity={0.8} />
  <mesh>
    <sphereGeometry args={[1, 32, 32]} />
    <meshStandardMaterial color="red" />
  </mesh>
</ThreeCanvas>
```

## 不允許非 `useCurrentFrame()` 驅動的動畫

著色器、模型等不得自行動畫。
除非由 `useCurrentFrame()` 驅動，否則不允許任何動畫。
否則，渲染時會導致閃爍。

禁止使用 `@react-three/fiber` 的 `useFrame()`。

## 使用 `useCurrentFrame()` 進行動畫

使用 `useCurrentFrame()` 來執行動畫。

```tsx
const frame = useCurrentFrame();
const rotationY = frame * 0.02;

<mesh rotation={[0, rotationY, 0]}>
  <boxGeometry args={[2, 2, 2]} />
  <meshStandardMaterial color="#4a9eff" />
</mesh>
```

## 在 `<ThreeCanvas>` 內使用 `<Sequence>`

任何在 `<ThreeCanvas>` 內的 `<Sequence>` 的 `layout` 屬性必須設為 `none`。

```tsx
import { Sequence } from "remotion";
import { ThreeCanvas } from "@remotion/three";

const { width, height } = useVideoConfig();

<ThreeCanvas width={width} height={height}>
  <Sequence layout="none">
    <mesh>
      <boxGeometry args={[2, 2, 2]} />
      <meshStandardMaterial color="#4a9eff" />
    </mesh>
  </Sequence>
</ThreeCanvas>
```
