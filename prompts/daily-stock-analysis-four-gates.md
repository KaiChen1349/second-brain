# 每日股票分析｜追加段落（貼進排程任務的提示詞最後面）

---

【分析框架：四關法 × 研究區（請每天套用）】

背景：期中選舉後，市場多了「資料中心監管變嚴、新建案延後、AI 基建成長假設下修」的不確定性。先別急著問買什麼，先學會排序。核心問題是：「下一美元 AI 資本支出，會流到哪裡？」

追蹤範圍：AI 主線價值鏈——GPU、ASIC、半導體、記憶體、光通訊、資料中心電力、冷卻、電網與基礎建設。

一、市場大跌時，三題分開回答：
1. 哪些趨勢最確定？
2. 哪些股票價格已修正到值得研究？
3. 哪些公司很好、但現在還不夠便宜？
（不要把「跌很多」誤認成「很便宜」）

二、每檔公司過四關：
- 第一關｜趨勢：未來 3–5 年誰會持續付錢？是否站在資本支出方向上？有無政策變數？
- 第二關｜證據：訂單 → 營收 → 利潤 → 現金流，有沒有真的走到財報上？（看 backlog、margin、FCF，扣掉一次性/預付款/庫存變動）
- 第三關｜預期：市場已相信什麼？共識 EPS、Forward P/E、預估上修或下修？好財報還能不能有驚喜？
- 第四關｜價格：離研究區多遠？還有沒有安全邊際？
前三關 = 趨勢確定性（高 / 中高 / 中），第四關 = 價格位置。

三、確定性 × 價格 = 行動等級（以 11/6 收盤為起點，每天檢查有無跨級）：
- 第一級 核心研究：NVDA、AVGO
- 第二級 分批觀察：TSM、VRT、ASE
- 第三級 小部位高風險：VST（政策風險）、LRCX（週期股）
- 第四級 等價格：PWR、GEV、ETN
請標出今天「誰升級、誰降級、為什麼」。

四、不給目標價，只給研究區：
研究區 = 估值回到這裡才值得重新研究財報，不是跌到就要買。EPS、Margin、CapEx、產品時程、利率、市場 multiple 任一改變，研究區都要重算。

五、事實與推估分開標示：
- 財報數字 → 公司新聞稿 / IR / SEC 申報
- 股價、倍數、共識預估 → Yahoo Finance / Morningstar / StockAnalysis
- 自行換算的 Forward P/E、EPS 成長率、折價幅度、EV/EBITDA、情境估值、研究區 → 標【推估】
- 公司 guidance → 標【公司指引】；新聞政策 → 標【消息】＋來源＋日期
- 查不到就寫「未查證」，不要編數字。

六、政策雷達（選舉後新增）：
- 追蹤資料中心審批、電力接入、電價分攤、環評等監管消息（特別是德州：據報州長當選人承諾暫停新資料中心審批，德州約佔美國規劃中資料中心容量四分之一——請每日查證最新進度）。
- 判讀規則：先問「影響的是哪一年的營收？」2027 年多已在 backlog/合約內，政策主要影響 2028 年以後的新案速度。只有傷到已簽約/施工中案子，才調降第一關；只影響新案時，調整的是 2028+ 成長假設（第三關）。
- 最直接受影響：VST、PWR、GEV、ETN、VRT。

七、輸出格式：
1. 今日一句話（幽默，可當 YouTube 開場）
2. AI 主線溫度計：資金今天流向價值鏈哪一段
3. 政策雷達
4. 四關快篩表（趨勢｜證據｜預期｜價格｜確定性｜行動等級｜今日變化）
5. 跨級異動
6. 三題分開回答
7. 給客戶/觀眾的白話版（3 句內、生活比喻）
8. 免責聲明：教育研究用途、非投資建議、不提供目標價；【推估】為個人假設、非公司指引。

語氣：淺顯易懂、可以幽默，但數字要準。
